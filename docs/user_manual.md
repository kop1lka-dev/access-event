# Руководство пользователя AccessEvent

**AccessEvent** — платформа инклюзивных мероприятий для людей с
нарушениями слуха и всех, кто ценит доступную среду. Все уведомления
показываются визуальными баннерами без звука.

## 1. Регистрация и вход

### Регистрация
1. Откройте главную страницу и нажмите **«Регистрация»** в верхнем меню.
2. Заполните поля:
   - **Имя пользователя** — как вас будут видеть другие (1–50 символов);
   - **Email** — действующий адрес, он будет логином;
   - **Пароль** — минимум 8 символов;
   - **Роль** — «Участник» или «Организатор».
3. Если вы глухой или слабослышащий — поставьте галочку
   «Я глухой или слабослышащий». Это включит инклюзивный режим.
4. При необходимости укажите особые потребности
   (например, «нужна сурдопереводная служба»).
5. Нажмите **«Зарегистрироваться»**.

Для слабослышащих пользователей: все подтверждения показываются
визуальными баннерами без звука; при ошибке ввода поле подсвечивается
красной рамкой.

### Вход
1. Нажмите **«Вход»** в верхнем меню.
2. Введите email и пароль.
3. Нажмите **«Войти»**.
4. После успешного входа вы попадёте в личный кабинет.

## 2. Просмотр мероприятий и фильтр

1. Откройте раздел **«Мероприятия»**.
2. Используйте фильтр **«Только инклюзивные»** — покажет мероприятия
   с жестовым переводом и визуальными уведомлениями.
3. В каждой карточке видны:
   - название и дата;
   - место проведения;
   - бейджи условий доступности (Инклюзивное / Сурдоперевод /
     Визуальные оповещения);
   - статус.

Для слабослышащих пользователей: у инклюзивных мероприятий на карточке
есть специальная цветная метка.

## 3. Создание мероприятия (для организатора)

1. Войдите под аккаунтом с ролью **organizer**.
2. В разделе «Мероприятия» нажмите **«Создать мероприятие»**.
3. Заполните название (до 100 символов), дату и время, место,
   описание.
4. При необходимости отметьте флажки:
   - **Инклюзивное**;
   - **Сурдоперевод**;
   - **Визуальные оповещения**.
5. Нажмите **«Сохранить»** — мероприятие появится в общем списке.

Для слабослышащих пользователей: успех создания подтверждается
зелёным визуальным баннером в правом верхнем углу.

## 4. Регистрация на мероприятие и статусы

1. Откройте карточку мероприятия.
2. Нажмите **«Зарегистрироваться»**.
3. Статус заявки виден в личном кабинете:
   - 🟡 жёлтый — **pending** (ожидание подтверждения);
   - 🟢 зелёный — **confirmed** (подтверждено);
   - 🔴 красный — **cancelled** (отклонено).

Для слабослышащих пользователей: смена статуса сопровождается
всплывающим визуальным уведомлением и сменой цвета бейджа.

## 5. Визуальные уведомления

Платформа **не использует звуковые сигналы**. Все оповещения —
визуальные баннеры в правом верхнем углу экрана:

- 🟢 зелёный — успех (регистрация, создание, подтверждение);
- 🔴 красный — ошибка (неверные данные, конфликт);
- 🔵 синий — информационное сообщение.

Баннер исчезает автоматически через 4 секунды.

## 6. Личный кабинет

В личном кабинете видны:

- профиль (имя, email, роль);
- отметка об инклюзивных потребностях (если включена);
- список ваших регистраций на мероприятия со статусами.

## 7. Инклюзивные особенности платформы

- Все уведомления — визуальные, без звука;
- Цветовые бейджи статусов дублируются текстом;
- Мероприятия с сурдопереводом помечены отдельной меткой;
- Форма регистрации спрашивает про особые потребности;
- При вводе некорректных данных поле подсвечивается — сообщение
  понятно без звукового сигнала.
