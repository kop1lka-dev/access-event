# access-event

Инклюзивная платформа мероприятий: помогает людям с ограниченными возможностями находить доступные события, а организаторам — публиковать их с указанием реальной доступности (пандусы, лифты, сурдоперевод, тактильные указатели и т.д.).

## Цель проекта

Сделать поиск и посещение мероприятий удобными для всех: собрать в одном месте события с честной информацией о доступности и дать организаторам инструмент для публикации.

## Возможности

- Поиск мероприятий по городу, дате и типу доступности
- Карточка события с описанием, местом и списком accessibility-опций
- Личный кабинет пользователя: избранное, регистрации, история
- Кабинет организатора: создание и редактирование событий
- Фильтры: пандус, лифт, сурдоперевод, тактильная навигация, места для колясок

## Стек

- Язык: Python 3.11
- Фреймворк: FastAPI
- База данных: PostgreSQL
- Контейнеризация: Docker
- CI: GitHub Actions
