# AccessEvent — инклюзивная платформа мероприятий

Веб-платформа для организации мероприятий, доступная людям с нарушениями слуха: визуальные уведомления вместо звуковых, цветная индикация статусов, фильтр по инклюзивным мероприятиям.

## Стек технологий

| Слой | Технология |
|------|------------|
| Backend | Python 3.11, Flask |
| База данных | PostgreSQL 16 (продакшен), SQLite (тесты) |
| Frontend | HTML5, CSS3, JavaScript, Jinja2 |
| Тестирование | pytest (14 тестов) |
| CI/CD | GitHub Actions (5 проверок) |
| Контейнеризация | Docker, docker compose, GHCR |
